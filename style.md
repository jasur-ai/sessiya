/* ═══════════════════════════════════════

--accent-purple:  #64748B;  /* Secondary accent */

## 5. Tipografiya

### 5.1 Font Stack (Deborah)

```css
--font-display: 'Righteous', cursive;   /* Sarlavhalar, kod, leaderboard */
--font-body:    'Nunito', sans-serif;    /* Asosiy matn */

/* Alternative options:
   --font-display: 'Outfit', 'Jakarta Sans', sans-serif;
   --font-body:    'Inter', sans-serif;
*/
```

### 5.2 Font Sizes (Scale)

```
─── Display ───
Title Large:  clamp(2.5rem, 7vw, 4.2rem)  → Landing page hero
Title:        clamp(1.4rem, 4.5vw, 2.6rem) → Question text
Subtitle:     clamp(1.1rem, 3.5vw, 1.9rem) → Active question

─── Body ───
Body Large:   1.0rem   → Question details
Body:         0.93rem  → Standard text  
Body Small:   0.85rem  → Secondary text

─── UI ───
UI Label:     0.78rem  → Button text
UI Small:     0.72rem  → Meta, badges
UI Tiny:      0.65rem  → Timestamps, counters

─── Display Numbers ───
Code Display: clamp(4rem, 14vw, 8rem) → Game code
Score:         3.5rem  → Final score
Timer:         1.4rem  → Countdown
```

### 5.3 Font Weights

```
--weight-regular: 400  (Nunito Regular)
--weight-semibold:600  (Nunito SemiBold)  
--weight-bold:    700  (Nunito Bold)
--weight-extrabold:800 (Nunito ExtraBold)
--weight-black:   900  (Nunito Black)
```

## 🎬 ANIMATION PERFORMANCE OPTIMIZATION

### Hardware Acceleration

```css
/* ── Best properties for 60fps animations ── */
/* ✅ transform (translate, scale, rotate) */
/* ✅ opacity */
/* ✅ filter (only with GPU support) */
/* ✅ clip-path (with GPU) */

/* ❌ Avoid: width, height, top, left, margin, padding */
/* ❌ Avoid: box-shadow (animating in loop) */
/* ❌ Avoid: border-radius (animating) */

/* ── Will-change hint (use sparingly) ── */
.will-animate {
  will-change: transform, opacity;
}

/* ── Forced GPU layer ── */n.gpu-layer {
  transform: translateZ(0);
  backface-visibility: hidden;
  perspective: 1000px;
}
```

### Reduced Motion Accessibility

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    transition-duration: 0.01ms !important;
    scroll-behavior: auto !important;
  }
}
```

### Animation Performance Checklist

```
□ Use transform + opacity only (60fps guaranteed)
□ Avoid layout-triggering properties (width, height, top)
□ Will-change only on active elements
□ Stagger delays produce smooth sequential reveals
□ Cubic-bezier overshoot creates organic spring feel
□ Linear() timing for true physics-based springs
□ Reduced motion for accessibility
□ GPU acceleration via translateZ(0) when needed
□ Animation fill-mode: both for smooth entries
□ Test on low-end mobile devices
```
